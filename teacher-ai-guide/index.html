01 · GPT WORK

흩어진 자료에서, 사용할 결과물까지

ChatGPT Work는 목표가 분명한 여러 단계의 업무를 맡기는 환경입니다. 자료 분석과 정리를 문서·스프레드시트·발표자료 제작으로 이어가 보세요.

공문 · 행정

요약을 넘어 해야 할 일 찾기

공문에서 업무, 제출자료, 기한, 담당부서를 추출하고 날짜순 체크리스트와 안내문 초안을 만듭니다.

첨부한 공문을 분석해 이번 주 처리할 업무를 제출기한 순으로 정리해줘. 업무명 / 해야 할 일 / 제출자료 / 기한 / 제출방법 / 담당부서 표로 만들고, 근거가 된 파일과 페이지도 표시해줘. 날짜가 불명확하면 확인 필요로 남겨줘.
수업 · 평가

자료를 연결해 수업 준비하기

교과서·지도서·성취기준을 바탕으로 수업안, 활동지, 평가문항, 채점기준의 초안을 준비합니다.

첨부 자료와 성취기준을 바탕으로 45분 수업안을 만들어줘. 도입 / 탐구활동 / 개념정리 / 확인문제로 구성하고, 단계별 시간과 학생 활동을 포함해줘. 활동지와 정답도 별도로 작성해줘.
분석 · 연수

분석을 다음 행동으로 연결하기

가상 시험 데이터의 문항별 정답률을 분석해 보충수업 계획을 만들거나, 참고자료를 비교해 연수 발표자료를 준비합니다.

가상 시험 결과에서 문항별 정답률을 계산해줘. 결측값 처리 기준과 계산식을 설명하고, 정답률 50% 미만 문항을 찾아 관련 개념별 보충수업 계획을 작성해줘. 원자료와 계산 결과를 함께 검토할 수 있게 해줘.

업무 영역별 프로젝트로 맥락 모으기

관련 자료와 지침을 묶어두면 요청할 때마다 배경을 반복 설명하는 수고를 줄일 수 있습니다.

02 · GPT CODEX

반복되는 불편함을, 나만의 도구로

Codex는 코드 작성·수정·검토·테스트를 돕는 AI 코딩 에이전트입니다. 누가 어떤 상황에서 사용할지, 어떤 기능이 필요한지를 자연어로 구체적으로 설명해 보세요.

수업용 웹앱

교실에서 바로 쓰는 작은 도구

  • 중복 없이 뽑는 랜덤 발표자 선택기
  • 조건을 반영하는 모둠·자리 편성기
  • 큰 화면의 타이머와 개념 퀴즈
  • 탐구 활동용 시뮬레이션

처음에는 입력창, 버튼, 결과 화면만 있는 도구부터 시작하세요.

평가 · 데이터

같은 계산을 매번 자동으로

  • 영역별 수행평가 점수 계산기
  • CSV 문항 정답률 분석 도구
  • 설문 응답 통계와 그래프
  • 단원·난이도로 검색하는 문제은행

계산식과 결측값 처리, 배점 합계를 직접 확인할 수 있게 요청하세요.

행정 자동화

파일 처리 규칙을 프로그램으로

  • 파일 이름 일괄 변경
  • 업무별 폴더 생성·파일 분류
  • 여러 CSV 파일 통합
  • 반복 양식의 문서 생성

변경 전 미리보기와 원본 백업, 되돌리기 기능을 함께 요청하세요.

코딩을 몰라도, 사용 장면은 구체적으로

목적 → 사용자 → 핵심 기능 → 조건 → 화면 → 테스트 순서로 설명하세요. 완성된 도구를 실행해 보고 “휴대폰에서 버튼이 잘려요”, “초기화 기능을 추가해 주세요”처럼 수정 요청을 이어갈 수 있습니다.

추천 시작 순서: 발표자 선택기·타이머 → 모둠 편성기·점수 계산기 → 문항 분석·문제은행 → 개인 업무 대시보드

04 · CLASSROOM & OFFICE

내 업무에 가까운 사례부터 살펴보기

아래는 활용 예시입니다. 실제 적용 전에는 학교 자료와 업무 기준에 맞게 요청문을 조정하세요.

수업 · Work + Codex

활동지와 개념 퀴즈 연결

Work로 수업안·활동지를 만들고 Codex로 피드백이 있는 퀴즈 웹앱을 제작합니다.

검토한 활동지의 핵심 개념 5개로 퀴즈 웹앱을 만들어줘. 문항별 답 선택, 정답과 해설, 다시 풀기 기능을 넣고 휴대폰에서도 보기 편하게 해줘. 모든 정답과 버튼 동작을 검토해줘.
수업 · Codex

모둠 편성 시간 줄이기

가상 명단으로 균등 배치, 특정 학생 분리, 출력 기능을 시험합니다.

가상 학생 번호를 붙여넣고 모둠 수를 정하는 편성 웹앱을 만들어줘. 모둠 인원 차이는 최대 1명으로 하고, 선택한 두 번호는 다른 모둠에 넣어줘. 불가능한 조건은 설명하고 결과 인쇄 기능을 추가해줘.
평가 · Work

성취기준별 출제 계획

기존 문항을 분류해 개념의 편중과 중복을 확인하고 채점기준 초안을 준비합니다.

기존 시험지와 성취기준을 분석해 25문항 출제 계획을 작성해줘. 상·중·하 2:5:3을 목표로 정수 문항 수를 제안하고 반올림 기준을 설명해줘. 합계는 25문항으로 맞추고 성취기준, 유형, 배점, 중복 개념을 표시해줘.
평가 · Codex

문항별 정답률 분석

가상 CSV를 입력하면 정답률과 취약 개념을 보여주는 반복 분석 도구를 만듭니다.

가상 응답 CSV를 브라우저 안에서만 분석하는 도구를 만들어줘. 정답률과 유효 응답 수를 보여주고 50% 미만 문항을 강조해줘. 빈칸 처리 기준을 명시하고 잘못된 열이나 값에는 오류 안내를 보여줘. 외부 전송은 하지 않도록 해줘.
행정 · Work + Codex

공문 정리에서 파일 분류까지

Work로 일정과 해야 할 일을 정리하고, Codex로 반복 파일 처리 도구를 만듭니다.

선택한 폴더의 파일을 업무별로 분류하는 도구를 만들어줘. 이동 전 원본 경로와 예정 경로를 표로 보여주고 확인 후 실행해줘. 파일명 충돌 시 덮어쓰지 말고, 작업 기록과 되돌리기 기능을 제공해줘.
연수 · Work

참고자료를 연수 흐름으로

보고서와 강의자료를 비교해 핵심 메시지, 실습, 토의 질문을 구성합니다.

첨부 자료를 바탕으로 교사 대상 2시간 연수안을 작성해줘. 개념 설명, 사례 탐색, 실습, 공유 시간으로 나누고 각 활동의 시간과 준비물을 표시해줘. 발표자료 개요와 출처 목록도 작성해줘.

05 · CONNECT THE WORK

06 · PRIVACY & REVIEW

실제 자료를 넣기 전에, 먼저 확인하세요

학교·교육청의 개인정보 보호 및 생성형 AI 이용 지침을 먼저 확인하고, 개발·연수 실습에는 가상 데이터를 사용하세요.

01
필요한 정보만 제공하기

이름, 학번, 연락처, 주소, 보호자 정보, 상담·건강·생활기록 내용은 실습 자료에서 제외합니다.

02
이름 변경만으로 안심하지 않기

학생 A로 바꾸어도 학급·사건·자유서술 내용으로 다시 식별될 수 있습니다. 불필요한 맥락도 제거하세요.

03
저장과 외부 전송 확인하기

입력 데이터가 어디에 저장되고 누구에게 보이는지, 외부 서비스로 전송되는지 확인하세요. 필요한 접근 권한만 허용합니다.

04
교사가 최종 판단하기

공문의 기한과 숫자, 문항의 정답과 배점, 분석 계산식을 원자료와 대조합니다. 프로그램은 예외 상황도 시험합니다.

연수에서는 이렇게 준비하세요

학생 A / 학생 B / 학생 C
가상 점수와 가상 응답 데이터

실제 학생 명단 대신 가상 번호로 기능을 검토하고, 파일 자동화는 복사한 실습 폴더에서 실행합니다.

실행 전 확인
입력 범위 · 저장 위치 · 외부 전송
접근 권한 · 원본 백업 · 오류 안내

이 사이트는 안내용입니다. 프롬프트 복사는 실행 요청을 전송하지 않으며, 외부 AI 서비스와 연결되어 있지 않습니다.

07 · YOUR FIRST 30 MINUTES

작게 만들고, 직접 쓰고, 한 번 더 개선하기

30분은 연수 진행을 위한 예시입니다. 계정 환경과 도구 제작 상황에 따라 조정하세요.

  1. 0–5분가상 자료 준비 · 목표와 확인 기준 정하기
  2. 5–15분Work 결과물 또는 Codex 작은 도구 요청하기
  3. 15–25분근거와 기능 확인 · 수정 요청 한 가지 하기
  4. 25–30분결과 공유 · 실제 업무 적용 조건 기록하기
실습 A · Work로 가상 공문 정리하기

가상 공문 3개를 아래 요청문과 함께 제공합니다. 결과의 기한, 준비물, 파일 근거가 원문과 일치하는지 확인하세요.

다음은 가상 공문이야. [공문 A] 수업나눔 신청: 10월 12일 16시까지 연구부에 신청서 제출. 행사는 10월 20일. [공문 B] 실험재료 수요조사: 10월 10일 12시까지 과학부에 수량표 제출. [공문 C] 독서행사 안내: 10월 15일 개최. 담임은 10월 11일까지 학급 안내문 배부. 교사가 해야 할 일을 기한순 표로 정리해줘. 업무 / 해야 할 일 / 기한 / 준비물 / 담당부서 / 근거를 포함하고, 행사일과 업무 마감일은 구분해줘. 없는 정보는 확인 필요로 표시해줘.
